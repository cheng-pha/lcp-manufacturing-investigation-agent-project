# Scrap Disposition Policy

## Purpose

This procedure defines when a device may be designated for scrap.

## Scrap Conditions

A device may be scrapped when a confirmed quality condition prevents the device from continuing through the manufacturing process.

Examples include:

- Confirmed contamination
- Failed final inspection
- Unrecoverable manufacturing defect

## Documentation

The scrap event must include:

- Device ID
- Scrap reason
- Reason code
- Timestamp
- Required approval

The agent should use documented scrap events as the source of truth when explaining why a device was scrapped.
